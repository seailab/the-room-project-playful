# The Room Project — Playful edition

Approved colourful website design, published separately for client review.

Website: https://seailab.github.io/the-room-project-playful/

This project is independent of https://seailab.github.io/the-room-project/ . The earlier design stays live in its original repository.

The approved static website is packaged in `the-room-project-playful.zip`. The GitHub Actions workflow verifies its SHA-256 and publishes it using the official GitHub Pages actions.

The review edition includes all public pages, original concept images, local fonts, self-hosted films, interactive artwork, galleries and a preview of the enquiry flow. GitHub Pages does not run the PHP backend or private CMS; this edition does not send or save enquiries. The full PHP/cPanel application remains separate. No database, credentials or private enquiries are included.
